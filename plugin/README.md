# presentation-craft

A Claude Code plugin that adds the `/presentation-craft` skill for designing and
building live interactive HTML presentations and local HyperFrames explainer
videos with selectable visual styles.

## Install

```text
/plugin install presentation-craft --marketplace victorarias/presentation-craft
```

On older Claude Code versions:

```text
/plugin marketplace add victorarias/presentation-craft
/plugin install presentation-craft@presentation-craft
```

Full documentation, style options, and starter templates are described at
https://github.com/victorarias/presentation-craft.
